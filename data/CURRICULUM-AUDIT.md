# 字数与完整性复核

2026-11-06 复核发现：原十二份教材附录的提取没有遗漏，但新旧版混用造成 **58 个旧版字表汉字未收录**。已将这些字加入独立「补充字」课程，包含认读、跟写和独立书写，共 6 颗星。网站现在共 **4,688 个学习字位、3,031 个不同汉字、472 颗星**。

原十二册仍为 4,630 个册内学习字位、2,973 个不同汉字、466 颗星；相对其原书识字表、写字表，漏字 0、多字 0、册内意外重复 0，末关没有截断。

这个结论不等于“2026 最新十二册全部无遗漏”。目前一至三年级采用 2022 课标修订教材存档，四至六年级仍为旧版。新旧版会调整汉字及其所在年级，不能把混合版次的总量直接当成一套最新教材的完整覆盖，也不能只按“3000字左右”凑数补字。

## 补齐版本差异

另从[深圳市福田区荔园外国语小学公开教材存档](https://lywgyxx.szftedu.cn/xkjc/yw/)逐册核验旧版一年级至三年级的完整识字表、写字表，六册各表的新字与写字数量均与原书印刷总数一致。与现用旧版四至六年级合并后，旧版基线为 2,996 个不同汉字。原混合字库为 2,973 字；旧版基线有 58 字不在其中，混合字库另有 35 字不在旧版基线，两者并集为 3,031 字。

58 个字包含“评、秤、秧、艳、苏、篇、绪”等。补充课程只放这些全库原本未收录的字，不把它们冒充某册新版官方字表。全部58字有原书识字表注音、页码与课次证据；其中20字还见于原书写字表。本站按用户希望，每个补充字都安排书写。前5关各10字，最后1关8字。

[补充字源数据](supplemental-source.json)保留逐字原页、源URL和PDF哈希；[读音与词语核验](supplemental-pronunciation-notes.md)说明选词；[新旧版覆盖清单](curriculum-coverage-baseline.json)保存旧六册的完整字符集合和此次差集，发布检查会断言这些字全部存在。完整PDF和课文不再分发。

这个补充保证覆盖本次已核验来源的并集。新版四至六年级的完整附录尚未取得并逐字核验，因此仍不能称“2026最新版全套无遗漏”。

## 怎么确认没有提取遗漏

1. 使用 Poppler 重新扫描全部 PDF 页面，自动找识字表、写字表及表末印刷总数，不沿用原提取脚本的硬编码页范围。
2. 对每一张完整附录按字符和出现次数与源 JSON 比较，再与实际发布的 JSON 比较。
3. 使用独立的 PDFium 引擎再按字形、字号、页面边界和文字颜色检查，确认黑色新字数与原书印刷总数一致，蓝色复习字另计。两种引擎逐字次数完全一致。
4. 检查十二册 PDF 的 SHA-256、网站的字符顺序，以及不足十字的最后一关；二上末关9字、二下末关3字均完整保留。

各册原书链接、PDF 页码和来源哈希见 [SOURCES.md](SOURCES.md)。机器可读的复核摘要见 [curriculum-audit.json](curriculum-audit.json)。研究用原页截图与完整 PDF 不随网站再分发。

原 PDF 放在 `data/research/g1s1.pdf` 等路径时，可用以下脚本复现（需 Poppler 和 Python 的 `pypdfium2`）：

```bash
python3 scripts/audit-curriculum-pdf.py
python3 scripts/audit-curriculum-glyphs.py
```

网站发布前的 `scripts/check-assets.mjs` 也新增了逐册与源字表的集合、顺序检查，避免以后构建时漏字而只检查现存字的音频和笔顺。
